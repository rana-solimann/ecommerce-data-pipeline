# E-Commerce Data Analytics & Data Quality Pipeline

A SQL-based data analytics project built using Oracle SQL to analyze e-commerce transactions, validate data quality, clean staging data, and generate business insights.

## Project Overview

This project simulates a small e-commerce database and demonstrates how SQL can be used to transform raw data into reliable business insights.

The project focuses on two main areas:
- **Data Analytics:** Analyzing customer orders, product performance, and revenue.
- **Data Quality & Transformation:** Identifying invalid records, validating data integrity, cleaning staging data, removing duplicates, and merging clean records into production tables.

## Technologies Used

- Oracle Database XE 21c
- Oracle SQL
- Oracle SQL Developer

## Database Schema

The project uses four main tables:

| Table | Description |
|---|---|
| Customers | Stores customer information |
| Products | Stores product details |
| Orders | Stores customer orders and their statuses |
| Order_Items | Stores products included in each order |

The relationships between these tables allow us to analyze customer purchases and product sales.

## Project Workflow

### 1. Database Creation & Sample Data

- Created the database tables.
- Defined primary and foreign key relationships.
- Inserted sample e-commerce data.

### 2. Revenue Analytics

Performed business analysis using SQL queries to calculate:

- Total delivered revenue.
- Monthly revenue trends.
- Revenue generated by each product.

**Important Business Rule:** Only orders with `DELIVERED` status are included in revenue calculations.

### 3. Data Quality Checks

Implemented SQL queries to identify potential data issues, including:

- Completeness checks.
- Validity checks.
- Referential integrity checks.
- Duplicate records.
- Missing or invalid values.

### 4. Pipeline Monitoring

Created a pipeline run log table to record execution information, including:

- Pipeline start time.
- Pipeline finish time.
- Number of processed rows.
- Execution status.

Also included a freshness check based on the latest available order date.

### 5. Data Cleaning & Transformation

Used a staging table to simulate incoming raw customer data.

Applied SQL transformations to:

- Remove unnecessary spaces using `TRIM()`.
- Standardize email addresses using `LOWER()`.
- Handle missing required values.
- Identify and remove duplicate records using `ROW_NUMBER()`.
- Keep the most recently updated record for each customer.

### 6. Loading Clean Data

Used the SQL `MERGE` statement to insert valid and cleaned staging records into the final Customers table.

This demonstrates a basic Extract, Transform, and Load (ETL) workflow.

## How to Run

1. Install Oracle Database XE 21c.
2. Open Oracle SQL Developer.
3. Connect to your database.
4. Open the SQL script located in the `sql/` folder.
5. Execute the script sections in order.
6. Review the generated analytics and data quality results.

**Note:** The script creates tables and inserts sample data. If the database objects already exist, use a fresh schema or reset the existing objects before running the full script again.

## Project Scope & Limitations

- This project uses a simulated e-commerce dataset.
- The pipeline demonstrates ETL concepts using SQL statements; it is not an automated scheduled ETL system.
- Pipeline execution information is represented by sample run-log data.
- Data freshness is estimated using the latest order date, not an actual automated pipeline execution timestamp.
- Business insights are based only on the provided sample data.
